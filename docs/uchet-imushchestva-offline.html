Учёт имущества без постоянного интернета

Связь может быть нестабильной, но учёт не должен останавливаться. Основная база Каптёрка PRO хранится локально на Android-устройстве, поэтому ключевые операции доступны без постоянного подключения.

01

Основной учёт локально

База приложения хранится на устройстве, поэтому обычные операции не зависят от постоянной сети.

02

Синхронизация — отдельная функция

Когда интернет доступен, данные можно синхронизировать между устройствами по ключу подразделения.

03

Понятное разделение данных

Ключ подразделения используется для разделения синхронизируемых наборов данных между группами.

Что работает без интернета

Основной локальный учёт рассчитан на работу непосредственно на телефоне: каталог, остатки и операции с имуществом не требуют постоянного соединения с сервером. Это важно, когда сеть пропадает или доступна только время от времени.

Когда интернет всё-таки нужен

Интернет требуется для сетевых функций: синхронизации между устройствами, входа в веб-кабинет и отдельных операций, связанных с онлайн-сервисами. Если синхронизация не используется, локальная работа с учётом остаётся основной.

Как безопаснее работать

  • Не передавайте ключ подразделения посторонним.
  • Перед важным обновлением сохраняйте резервную копию.
  • После длительной работы без сети дайте синхронизации завершиться при стабильном соединении.
  • Не удаляйте приложение ради обновления, если официальная новая версия устанавливается поверх текущей.
Локальная база приложения использует Room/SQLite. Синхронизация является дополнительной сетевой функцией и не заменяет резервное копирование важных данных.
