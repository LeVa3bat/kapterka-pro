Где находятся данные учёта

Основная база Android-приложения хранится локально на устройстве с использованием Room/SQLite. Поэтому базовые операции учёта доступны без постоянного подключения к интернету.

Текущая публичная документация не заявляет отдельное шифрование локальной Room-базы, если оно не подтверждено конкретной версией приложения.

Когда данные передаются в сеть

1
СинхронизацияКогда пользователь включает совместную работу, выбранные данные передаются через Firebase и разделяются по ключу подразделения kapt_....
2
Личный кабинетДля сайта используется Email и вход по одноразовому коду. Пароль сайта не требуется.
3
ОплатаБанковские реквизиты обрабатываются ЮKassa. Сайт Каптёрка PRO не хранит номер банковской карты.
4
Аналитика сайтаПродуктовые события не передают лицензионный ключ, ключ подразделения, Email или позывной.
