Обновление поверх установленной версии

Официальная версия 3.6.1 предназначена для установки поверх предыдущей рабочей версии при совпадающей подписи пакета com.aistudio.kapterka.jmwqve. Текущий APK автоматически проверяется по package, версии, SHA-256 и сертификату подписи.

Перед важным обновлением дождитесь завершения синхронизации и при необходимости выгрузите отчёты в Excel. Не удаляйте установленное приложение только ради обновления — при обычной установке новой версии поверх старой локальная база должна сохраняться.

Синхронизация

Персональная лицензия отвечает за доступ PRO, а ключ подразделения вида kapt_... объединяет устройства, которым нужен общий контур данных. Основной учёт продолжает работать локально, а сетевой обмен выполняется при наличии связи.

  • используйте один и тот же ключ подразделения только на нужных устройствах;
  • не передавайте ключ подразделения посторонним;
  • при проблеме сначала проверьте интернет и одинаковый ключ подразделения на устройствах.
