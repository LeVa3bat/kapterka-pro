3. Состав и категории обрабатываемых данных

Для функционирования сервиса обрабатывается исключительно минимально необходимый перечень данных, добровольно предоставляемых пользователем:

  • Позывной / Имя: используется исключительно для отображения авторства в приходных/расходных операциях учета.
  • Условное наименование подразделения: для группировки складских книг.
  • Адрес электронной почты (Email): при указании используется исключительно для отправки фискальных чеков при оплате лицензий и восстановления доступа.
  • Идентификационный код подразделения (Unit Key): технический токен для сквозной синхронизации между мобильными устройствами подразделения.
🛡️ Локальное хранение учетных сведений (Offline-First):
Все номенклатурные списки, количества материальных средств, боеприпасов, акты списания (Форма № 8) и ведомости учета (Форма № 18) хранятся в изолированной зашифрованной локальной базе данных SQLite на пользовательском устройстве. Сервер не имеет доступа к вашим складским книгам и не осуществляет их сбор или передачу третьим лицам.
