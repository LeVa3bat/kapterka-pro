1. Общие положения

Настоящая Политика описывает порядок обработки и защиты данных на сайте kapterka-pro.ru и в Android-приложении «Каптёрка PRO» в соответствии с Федеральным законом № 152-ФЗ «О персональных данных». Мы собираем только минимальный объём сведений, необходимый для входа по почте, лицензирования, поддержки и добровольно включённой пользователем синхронизации.

2. Какие данные обрабатываются

  • Email: для регистрации и входа по одноразовому 6-значному коду (без входа через Google-аккаунт и без хранения паролей), отправки лицензионного ключа и связи с поддержкой.
  • Имя / позывной, название склада и должность: указываются пользователем добровольно для отображения в профиле и отчётах.
  • Код группы синхронизации (kapt_...): случайный технический идентификатор для разделения данных между командами.
  • Данные синхронизации (если включена): склады, карточки имущества, остатки, журнал операций, заявки и список подключённых устройств (случайный код устройства, модель телефона, время последней активности).
  • Сессионный токен сайта: хранится в браузере, на сервере хранится только его SHA-256 хэш.
  • Техническая аналитика сайта: на сайте используются Google Analytics и Яндекс Метрика с отключённым Вебвизором (webvisor: false). Лицензионные ключи, коды групп, Email и вводимые списки в аналитику не передаются.

3. Где хранятся данные и как работает вход по Email

На устройстве (Offline-First):
Основная база приложения хранится локально в изолированном хранилище Android с использованием Room/SQLite. Мы честно указываем: отдельное аппаратное шифрование файла локальной Room-базы не заявляется, поэтому используйте системную блокировку экрана устройства.

Авторизация по Email, выдача одноразовых 6-значных кодов и проверка лицензий выполняются серверным API kapterka-api (Cloudflare Workers) с хранением серверных реестров в защищённых коллекциях без клиентского доступа. Пароль не создаётся и не хранится; вход через Google-аккаунт не используется.

4. Синхронизация приложения и управление облаком

Если пользователь включает совместную работу, данные синхронизируются через облачное хранилище Firebase (Firestore) и изолируются по коду группы kapt_.... Соединение защищено TLS-шифрованием, однако сквозного (end-to-end) шифрования нет, поэтому код группы нельзя публиковать и передавать посторонним. Оператор не просматривает и не использует складские данные пользователей в своих целях.

В Android-приложении отсутствуют рекламные SDK и трекеры поведения. Отчёт о сбое сохраняется локально и отправляется только по явному нажатию пользователя.

4.1. Как отключить синхронизацию и удалить данные из облака

  • Приостановить синхронизацию: окно «Подключить» → «Приостановить синхронизацию». Обмен с облаком прекращается, локальные данные и код группы остаются на телефоне.
  • Удалить данные из облака: окно «Подключить» → «Удалить данные из облака (на телефоне останутся)», подтверждается вводом кода группы. Облачные данные удаляются, учёт на телефоне сохраняется.
  • Полная очистка учёта: «Ещё» → «Опасная зона». Удаляет остатки, операции и заявки на устройстве и отправляет маркеры удаления другим устройствам группы.

5. Оплата (Самозанятый НПД и ЮKassa)

Оплата лицензии PRO проводится через ЮKassa (СБП, карты МИР, SberPay). Платёжные реквизиты карты обрабатываются на стороне ЮKassa и не сохраняются сайтом или приложением. Правообладатель работает как самозанятый (НПД, ИНН 250104230398); Email используется для автоматической отправки ключа лицензии и, при обращении, предоставления чека НПД («Мой налог»).

Калькулятор сверки на странице инвентаризации работает полностью в памяти браузера и не отправляет ваши позиции на сервер.
