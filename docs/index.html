Частые вопросы

Нужен ли постоянный интернет?

Нет. Основной учёт работает на телефоне без сети. Интернет нужен для синхронизации между телефонами, оплаты и проверки лицензии.

Как подключить второй телефон?

На первом телефоне нажмите «Подключить» — появится QR-код подразделения. На втором телефоне при входе нажмите значок QR и наведите камеру. Ключ можно ввести и вручную.

Какие отчёты можно сформировать?

Форму № 8 (раздаточная ведомость), книгу учёта по форме 18, сводную ведомость остатков и реестр заявок. Всё выгружается в Excel.

Сколько стоит?

3 дня полного доступа бесплатно, затем PRO — 490 ₽ за 30 дней. Оплата через ЮKassa: СБП, карта МИР, SberPay.

Можно обновить поверх старой версии?

Да. Официальная сборка ставится поверх установленной, склад, журнал и лицензия сохраняются.

Зачем приложению камера?

Только для сканирования QR-кода подразделения. Приложение не снимает фото и видео.

Второй телефон — по QR-коду

1Откройте «Подключить»На главном экране первого телефона — появится QR-код подразделения

Доступ к данным подразделения получают только его участники. QR-код не даёт больше, чем сам ключ.

Конфиденциальность

Основная база приложения хранится локально в Room/SQLite. При включённой синхронизации выбранные данные передаются через Firebase по ключу подразделения.

Сайт использует Email для входа по одноразовому коду, ЮKassa для оплаты, а также Google Analytics и Яндекс Метрику для технической аналитики.
