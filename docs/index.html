Частые вопросы

Можно обновить приложение поверх старой версии?

Да, официальная сборка предназначена для обновления поверх установленной версии с той же подписью. Перед важным обновлением всё равно рекомендуется сохранить резервную копию.

Приложению постоянно нужен интернет?

Нет. Основной учёт работает локально на телефоне. Интернет нужен для синхронизации между устройствами и сетевых функций.

Пароль не нужен: на указанный Email приходит одноразовый 6-значный код подтверждения.

PRO предоставляется на 30 дней. Оплата проводится через ЮKassa, после подтверждения используется лицензионный ключ.

Совместная работа

Синхронизация подразделения

Персональная лицензия отвечает за доступ, а общий ключ kapt_... объединяет устройства одного подразделения.

01

Персональная лицензия

KAPT-XXXX-XXXX-XXXX

Принадлежит пользователю и не меняется при переходе в другое подразделение.

+
02

Ключ подразделения

kapt_xxxxxx

Одинаковый код на устройствах, которые должны видеть общий склад.

Безопасность

Не передавайте ключ подразделения посторонним

Ключ kapt_... используется для разделения данных подразделений. При смене состава его можно заменить в кабинете или приложении.

Конфиденциальность

Основная база приложения хранится локально в Room/SQLite. При включённой синхронизации выбранные данные передаются через Firebase по ключу подразделения.

Сайт использует Email для входа по одноразовому коду, ЮKassa для оплаты, а также Google Analytics и Яндекс Метрику для технической аналитики.
