## Что выполняется без ПК

GitHub Actions уже выполняет проверки сайта в облаке. После разрешённого развёртывания обновлённый IndexNow запустится в том же workflow, сохранит квитанции и журнал в существующем Actions-хранилище. Само развёртывание остаётся ручным после команды владельца. Каталоги, решения модерации, вход и обновление APK в Uptodown не выдаются за настроенный автоматический pipeline. Порядок следующих обновлений и read-only проверка APK: `catalogs/APK_UPDATE.md`, `tools/growth/catalog-apk-check.mjs`.
