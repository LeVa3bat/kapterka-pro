Отчёт: `workshop-xlsx-checks.json`.
- 26 проверок в настоящем Microsoft Excel 16.0. Книги открыты, пересчитаны и сохранены. Повторены существенные граничные сценарии на временной копии, включая дублированный код. В итоговом примере `Журнал!A8` отображает `01.10.2026`, хранит числовую дату `46296`. Отчёт: `workshop-native-excel-checks.json`.
- 19 проверок итоговых пакетов и QR. Сохранённые XLSX содержат 6 правил ввода с остановкой неверного значения и разрешением пустого поля, 4 правила условного выделения, кликабельный источник и QR. В кэшах формул нет ошибок, макросов нет. Отчёт: `workshop-package-checks.json`.
- QR декодирован через zxing-cpp 3.1.1 из обеих конечных книг, обоих превью инструкций и всех 5 страниц PDF. Проверены цветные и чёрно-белые растры PDF при 120 dpi. Все коды ведут ровно на указанную страницу комплекта.
- Все 5 страниц PDF и все 3 листа обеих книг визуально просмотрены. Проверены читаемость, поля, переносы текста, русские символы и отсутствие обрезки. PDF имеют размер A4 297 × 210 мм, источник и номер страницы внизу. Превью лежат рядом с этим отчётом.
- В `docs/downloads/` оставлены только 5 публичных файлов. Генераторы, результаты проверок и изображения для QA находятся вне публикуемого каталога.

## Ограничения

- Шаблон рассчитан на 30 позиций с неизменными кодами W001-W030 и 300 движений. Расширение диапазонов сверх этой ёмкости не обещается.
- Журнал заполняется по порядку событий. Его строки нельзя сортировать, поскольку остаток после записи считается по порядку строк. Начальный остаток означает физическое количество на полке.
- Возврат из предыдущего периода вносят как приход с пояснением. Движение с неполными или неверными обязательными данными исключается из итогов и отмечается «В расчёте = Нет». Вставка через буфер может обходить ограничения Excel, поэтому видимые проверки сохраняются.
- Печатные макеты проверены цифровым рендером и декодированием QR. Физическая печать на конкретном принтере не выполнялась. Печатать PDF следует на A4 в альбомной ориентации с обычными полями.
- Native hyperlink и настройка разрешения пустых полей добавлены через установленный Excel, поскольку соответствующие настройки bundled artifact-tool неполны. Данные, формулы, стили, исходные проверки ввода и QR созданы artifact-tool. Превью дат у artifact-tool ограничено; фактический вид даты подтверждён через Excel.
- Новые постоянные доступы, платные сервисы, аналитику внутри файлов и отправку данных не подключали. Для машинной проверки QR использован бесплатный временный пакет вне репозитория.

## Воспроизведение

1. `tools/growth/build_workshop_pdfs.py` создаёт PDF, исходные вымышленные данные и QR с bundled Python/ReportLab.
2. `tools/growth/build-workshop-xlsx.mjs` создаёт обе книги с bundled Node и artifact-tool. Для запуска нужен временный каталог с junction `node_modules` на bundled зависимости. Рекомендуемый параметр Node: `--max-old-space-size=6144`.
3. `tools/growth/verify-workshop-excel.ps1` выполняет проверки в установленном Excel, добавляет native hyperlink, разрешает пустые поля и сохраняет конечные книги. Проверки с изменением количества работают только на временной копии.
4. `tools/growth/verify-workshop-files.py` проверяет конечные XLSX/PDF и QR. Передать путь репозитория и временный каталог с установленным `zxing-cpp`.

Для локального коммита нужны 5 публичных файлов, 4 перечисленных служебных скрипта и этот отчёт с тремя JSON-отчётами. По желанию можно сохранить QA PNG, `workshop-example-source.json` и `workshop-source-qr.png`. Файлы `.py` игнорируются общим правилом репозитория, поэтому два служебных Python-скрипта нужно добавить явно через `git add -f`. Ветка комплекта: `work/free-growth-kit-2026-10`. Коммит агент комплекта не выполнял.
