## Важно при обновлении

Не удаляйте и не меняйте существующую конфигурацию подписи релиза без проверки последствий. Новые APK должны устанавливаться поверх опубликованной версии с сохранением пользовательских данных.

Приватный keystore, пароли, токены и локальные `.env`-файлы нельзя коммитить в GitHub.

Перед публикацией обновления проверяйте:

- установку поверх предыдущей версии без удаления приложения;
- сохранность профиля, лицензии и локальной базы;
- package, versionName и versionCode;
- сертификат подписи;
- синхронизацию и ссылку на APK на сайте.
