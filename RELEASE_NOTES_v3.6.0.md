# Kapterka PRO 3.6.0 (код 33) — итоги на 24.09.2026

## Приложение

- Новый интерфейс: плавающая нижняя панель с иконками, плавные переходы без подёргиваний, заставка ~4,5 с (можно пропустить касанием).
- Вибро-отклик на операциях: успех, предупреждение, выбор.
- Долгое нажатие на склад: выше / ниже / изменить / удалить, с анимацией.
- Раскрытый склад: названия в две строки, остаток виден полностью.
- Операции: журнал по дням со сворачиваемыми заголовками, фильтр «Сегодня / 7 дней / 30 дней», подгрузка по 60, кнопка «наверх».
- Заявки: доска по этапам «Новая → Собирается → Собрана → Выдана», проверка остатка, пометка «срочно», выдача проводится со склада.
- Подключение второго телефона по QR-коду (камера — только для QR), копирование и отправка ключа.
- Новое окно лицензии: срок действия, преимущества, оплата, «Я оплатил — проверить», восстановление.
- Форма № 8 (раздаточная ведомость) и форма № 18 (книга учёта по наименованиям) в Excel по образцу.
- Встроенное руководство (8 разделов), ссылки на сайт и Telegram.
- Секретное меню: удаление только тестовых пользователей (без лицензии).
- Размер APK ~5 МБ вместо ~18 МБ (R8 удаляет неиспользуемый код).

## Сервер (kapterka-api)

- Почта: диагностика ретранслятора, таймаут 28 с, код в заголовке и теле письма, понятная причина ошибки.
- Оплата: неизвестный платёж → «не найден», ошибка ключей → PAYMENT_GATEWAY_AUTH.
- Удаление тестовых пользователей защищено: пользователь с лицензией не удаляется.
- Ежедневная проверка в CI: здоровье сервера, почта, оплата.

## Проверено

- Почта (код приходит), оплата (ключи ЮKassa действительны), доступность синхронизации, правила Firestore, модульные тесты сервера (35/35) и приложения, снимки экранов в CI.

## Публикация

- Сайт kapterka-pro.ru: новый дизайн, галерея, руководство, SEO-страницы (Форма 8, программа для старшины), рекомендации Яндекс Вебмастера выполнены.
- RuStore: новые скриншоты, баннер 16:9, описание разрешений.
- Telegram-канал: пост с баннером и APK.
- 4PDA: релиз 3.6.0 через «Релизер» (сообщение №4), запрос куратору на обновление шапки.

## Известные ограничения

- У части операторов синхронизация работает только через VPN (Firebase).
- Строгие правила Firestore ещё не включены (переходный режим).
- Нет сбора отчётов о сбоях и нет резервной копии базы в файл.
