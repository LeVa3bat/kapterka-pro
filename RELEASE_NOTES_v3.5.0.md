# Kapterka PRO 3.5.0 (код 32)

## Оплата перенесена на сервер

- Оплата теперь проходит через собственный сервер `kapterka-api`, а не напрямую из приложения.
- Секретный ключ ЮKassa удалён из приложения — его больше нельзя извлечь из APK.
- Исправлена ошибка «Ошибка шлюза» при оплате в приложении.

## Что это даёт

- Безопасность: ключи оплаты хранятся только на сервере и могут быть обновлены без выпуска новой версии приложения.
- Надёжность: при проблемах с ключами достаточно обновить настройки сервера, а не собирать новый APK.

## Технические детали

- `YooKassaPaymentService` обращается к backend-эндпоинтам `create` и `check`.
- Активация лицензии после оплаты работает как раньше.
