# Каптёрка PRO 3.7.0 (код 35) — «Надёжность»

## Что нового для пользователя

- **Резервная копия в файл.** Вкладка «Ещё» → «Резервная копия» → «Сохранить». Файл можно положить на Google Диск или перенести на другой телефон и восстановить кнопкой «Восстановить». Раз в неделю приложение само сохраняет копию в свою папку.
- **Облачная копия подразделения.** Кнопки «В облако» и «Из облака»; при подключённом общем учёте копия обновляется раз в сутки. Хранится одна последняя копия.
- **Восстановление откатывает всё подразделение.** После восстановления из файла или из облака остальные телефоны подразделения получают то же состояние, перед заменой приложение сохраняет текущие данные в свою папку.
- **Статус синхронизации на кнопке «Синхр.»:** «только что», «N мин назад», «идёт…», «нет сети», «нет связи», «не подключено». Когда интернет возвращается, синхронизация запускается сама.
- **Отчёт о сбое.** Если приложение закрылось с ошибкой, в «Ещё» появляется отчёт (версия, модель телефона, техническая запись, без личных данных) с кнопкой «Отправить».

## Совместимость и данные

- Ставится поверх 3.6.1 и старых версий без удаления: `applicationId`, подпись и схема базы (Room v3) не менялись.
- В копию входят склады, остатки, операции, заявки и справочник имущества. Лицензия и ключи в копию не входят: лицензия хранится на сервере.
- Правила Firestore и сервер (Cloudflare Worker) не менялись. Облачная копия лежит в поле `cloudBackup` документа подразделения, старые версии его не читают.

## Что не вошло (по плану)

- Синхронизация без VPN (перенос на свой сервер): отложена.
- Строгие правила Firestore: отложены до переноса синхронизации, иначе могут сломать старые версии.
- Отчёты о сбоях в AppMetrica/Crashlytics: нужен ключ из их кабинета; пока отчёт только локальный.

## Проверено

- Сборка приложения, проверки `android-invariants`, `site-smoke`, тесты Worker (35/35).
- Работа копий, статуса и восстановления проверена владельцем на телефоне.
- Модульные тесты приложения (включая `BackupTest`) выполняются в CI: локально Robolectric не скачивает библиотеку без сети.

## Известные ограничения

- Облачная копия одна и заменяется раз в сутки: перед рискованными действиями сохраните отдельный файл.
- Облако работает через Firebase, поэтому у операторов, которым нужен VPN, оно тоже требует VPN.
- Копия не должна превышать примерно 900 КБ в сжатом виде; для очень больших складов используйте файл.
