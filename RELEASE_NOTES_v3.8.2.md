# Каптёрка PRO 3.8.2 (код 38)

Исправлено получение лицензии PRO после оплаты через ЮKassa.

- Возврат со страницы оплаты продолжает проверку платежа. Если платёж ещё обрабатывается или связь временно пропала, приложение повторяет проверку автоматически.
- После перезапуска приложения проверка ожидающего платежа возобновляется. Повторная проверка не создаёт новый счёт.
- PRO включается только после подтверждения оплаты сервером и получения действующего ключа со сроком лицензии.
- Отправка письма с ключом выполняется сервером в фоне и не задерживает активацию в приложении. Повторная отправка из приложения остаётся доступной.
- Исправлен возврат после оплаты в отдельную тестовую сборку NEXT-SAFE.

Сохраняются поддержка Android 7.0 и выше, прежняя подпись приложения и данные учёта. Пакет приложения и схема базы данных не меняются.
